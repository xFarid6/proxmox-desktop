# Licensing, in plain language

This project is licensed under the **Functional Source License, Version 1.1,
with MIT Future License (FSL-1.1-MIT)** — the same license used by Sentry and
Turso. The binding text is in [LICENSE](LICENSE); this file is a summary, not
a substitute.

What it means in practice:

- **The owner (xFarid6) can do anything** — run it, sell it, offer it as a
  paid product or service, relicense it. The FSL restricts *licensees*, not
  the licensor.
- **You can read, use, modify, and redistribute** the code for basically any
  purpose — internal use, education, research, building non-competing things
  on top.
- **You cannot take this code and sell a competing product or service with
  it** (a "Competing Use") while a given version is under embargo.
- **Each version automatically becomes plain MIT two years after its
  release.** Old versions open up on a rolling basis; only the recent ones
  are protected.

For contributors: contributions land under the same license. That keeps the
project sellable as a commercial product while guaranteeing everything
eventually becomes MIT.
